# Changelog

Every release is listed, with its notes, on the
[GitHub releases page](https://github.com/M4RC0Sx/rustmy/releases), and in
[`CHANGELOG.md`](https://github.com/M4RC0Sx/rustmy/blob/master/CHANGELOG.md).
Versions follow [Semantic Versioning](https://semver.org), and the entries
come from the [Conventional Commit](https://www.conventionalcommits.org)
titles of the pull requests.
